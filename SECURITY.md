# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security → Report a vulnerability** flow for this repository. Do not include tokens, private note contents, repository contents, or other sensitive data in a public issue.

Include the affected plugin version, Obsidian version, platform, impact, and minimal reproduction steps. A fix and disclosure timeline will depend on severity and complexity.

## Scope

Security reports involving GitHub authentication, unintended file upload or deletion, path handling, secret exposure, or remote repository integrity are in scope.
